LG Remote Android

Esto SÍ es una app Android nativa.

Qué hace:
- Busca TVs LG/webOS en la red local desde el móvil.
- Permite seleccionar la TV encontrada.
- Vincula la TV una vez.
- Guarda la clave de vinculación.
- Después controla la TV sin servidor, sin PC y sin anuncios.

IMPORTANTE:
La primera vez LG obliga a aceptar el aviso en la TV.
No se puede saltar por seguridad.
Después la app guarda la clave y no debería volver a pedirlo.

Cómo compilar:
1. Abre esta carpeta con Android Studio.
2. Espera a que sincronice Gradle.
3. Pulsa Run para instalar en el móvil.
4. También puedes generar APK desde:
   Build > Generate App Bundles or APKs > Generate APKs

Permisos usados:
- INTERNET
- ACCESS_WIFI_STATE
- CHANGE_WIFI_MULTICAST_STATE
- ACCESS_NETWORK_STATE
